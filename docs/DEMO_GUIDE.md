# 演示视频录制流程

演示由提交者自行录制。推荐长度 **1.5～2 分钟**，录制桌面浏览器，使用光线充足、背景简洁的环境。可使用系统录屏保留完整操作，也可点击页面底部「录制创作过程」录制画布与识别视窗。

页面内录制不包含音轨，最多 3 分钟；桌面 Chrome / Edge 通常导出 WebM，可用剪辑软件转换为 MP4。系统录屏更适合加旁白、展示按钮操作和权限授权。

| 时间 | 操作画面 | 可参考的旁白 |
| --- | --- | --- |
| 0～15 秒 | 打开程序，展示整个界面 | 这是我设计的「空中画室」，使用 MediaPipe Hand Landmarker，将手指动作转换为画布上的绘画操作。 |
| 15～35 秒 | 开启摄像头，允许权限，手掌完整入镜；展示右侧 21 个关键点 | 模型在本机浏览器识别 21 个手部关键点。食指尖决定笔尖位置，拇指与食指距离决定是否落笔。 |
| 35～65 秒 | 捏合画一条线；张开移动到另一位置；再捏合画第二条 | 捏合时落笔，分开时抬笔。程序对坐标做平滑处理，并用两个阈值减少抖动。 |
| 65～85 秒 | 抬笔后悬停色块换色，再画；切换橡皮擦除部分内容 | 在顶部色块停留约 0.7 秒可以换色；也支持画笔粗细和橡皮工具。 |
| 85～105 秒 | 撤销、重做、保存 PNG；打开导出的图确认 | 笔画有历史记录，支持撤销重做，并可导出 1600 × 1000 的作品。 |
| 105～120 秒 | 展示识别设置 / 代码目录 | 推理在 Worker 中进行，UI 不等待同步识别；摄像头帧只在本地处理。源码和调研说明位于提交的仓库中。 |

## 录制前检查

1. 先跑一次真人摄像头流程，确认能稳定显示关键点。
2. 捏合过于灵敏就将灵敏度向左调；难以落笔则向右调。
3. 从简单图形开始，例如太阳、花朵、笑脸或自己的首字母。
4. 用手势画出的部分明确标为摄像头输入；若展示鼠标或导入素材，说明输入来源。
5. 如果浏览器弹出权限提示，把授权过程一起录下来即可。
6. 结束后回看视频：关键点可见、捏合与笔画因果清楚、导出的作品正确，且没有私人信息出现在画面中。

## 建议提交内容

- 代码仓库：`https://github.com/yeyu6523/mediapipe-air-canvas`
- 自己录制的演示视频：MP4 / WebM 或老师允许的视频链接。
- 简短说明：项目基于 HTML / JavaScript + MediaPipe，实现手势绘画、悬停换色、历史撤销和图片导出；详见仓库 README 和调研文档。

本仓库没有把合成测试素材包装成真人录制的证明。`assets/hand-motion.mp4` 仅用于验证视频输入与真实模型推理，不适合作为真人手势交互演示。
