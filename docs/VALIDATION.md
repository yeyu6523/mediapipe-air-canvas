## 边界和待使用者验证的内容

- **没有完成真人摄像头捏合绘画实测。** 已完成的素材识别与几何判定测试，不等于在真人摄像头下验证整个链路。
- 悬停换色时长、捏合迟滞、两帧确认、手部消失重置已通过单元测试，但仍需使用者以真实手部进行体验和调参。
- 模拟权限拒绝只证明错误提示路径；不证明所有摄像头硬件的兼容性。
- 手机端检查了布局与无变形画布，未在所有移动浏览器测试摄像头和 Worker GPU 能力。
- 看到的模型推理耗时约数百毫秒，取决于本次设备 / 浏览器；不是实时帧率保证。界面实时显示单次推理耗时。
- 本次用户明确选择自行录制演示，因此不提供代录视频，也不把测试录制文件充当演示视频。

## 测试期间修复

1. 固定版本 MediaPipe 在模块 Worker 下加载 WASM 报 `self.import is not a function`：改用 classic Worker + 官方 CommonJS bundle，实际推理验证通过。
2. 自动化测试清理存储被应用离开时的自动保存覆盖：测试先离开页面，再用 CDP 清理存储后重新打开；不修改应用正常保存逻辑。
3. 初版移动画布显示为 4:3，导致内部 16:10 画面拉伸：统一到 16:10，重新截图验证空状态与错误状态。
4. 初版辅助字过小、浅色文本对比不足：提高功能文案字号并加深次要文字颜色，再截图检查。
5. 慢速设备两次推理间隔可能超过 250 ms：把手势观察超时设为 1000 ms，并增加 350 ms 帧间隔的捏合确认回归测试，避免每帧重置导致无法落笔。

## 复现

先 `npm start`，保持服务运行，再在第二个终端依次执行 README 中的测试命令。Playwright CLI 需要首次联网准备其依赖；这属于开发测试环境，不是应用运行时依赖。测试会操作并清理测试浏览器中的画作，勿在自己正在使用的浏览器会话中附加执行。
